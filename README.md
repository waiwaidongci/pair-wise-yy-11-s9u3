# hxyfront-62010 潜水气瓶充填记录

源提示词编号：5

潜水店气瓶充填前端，已将页面升级为**气瓶充填工位闭环**：

- **编号唯一**：气瓶编号重复登记会被拒绝。
- **开工禁区**：检验过期、耐压不足或余气冲突的气瓶不得开工，仅可「排空」或「送检」。
- **工位闭环**：一工位只接一瓶；开工即锁定气瓶、操作员与气源批次。
- **气源失效**：批次标记失效即在充工单暂停；须换合格批次并重验后才能续充。
- **超限留档**：实测氧/氦/压力超允差只能留档转复核，复核不改实测，确认后重新入队。
- **签收与换单**：实测合格方可签收；签收后换配气单，原签收立即失效、新单回队列。
- **并发安全**：重复/并发开工仅生效一次，其余请求被拒绝。
- **刷新一致**：队列、工位、历史同源持久化（localStorage），刷新后一致。

## 分层结构（规则 / 存储 / 展示分离）

```
src/
  domain/       业务规则层（纯函数，不含 UI 与存储）
    types.ts        领域模型
    rules.ts        允差、禁区判定、开工校验、超限判定
    transitions.ts  状态迁移（开工/暂停/续充/实测/复核/签收/换单/排空/送检）
    seed.ts         演示数据
  storage/
    persistence.ts  localStorage 读写
  store/
    createStore.ts  单一状态源 + 同步 dispatch（前置校验与落库同事务）
    appStore.ts     应用 store 实例
  components/       展示层（只读状态 + 触发迁移）
```
